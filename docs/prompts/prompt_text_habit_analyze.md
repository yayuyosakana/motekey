以下はユーザーが実際にパートナーへ送ったメッセージのサンプルです。

【サンプルデータ】
{samples}

---

上記のサンプルをもとに、以下の6つの観点でユーザーの口調を分析し、
結果を下記のJSON形式のみで出力してください。
前置きや説明文は一切不要です。JSONのみを返してください。

---

# 分析観点

1. **語尾のクセ**
   - 「〜だよ」「〜じゃん」「〜かな」など、頻出する語尾パターンを特定する

2. **絵文字・記号の使い方**
   - 使う頻度、どのタイミングで使うか（笑、！、…など）

3. **共感・リアクションの表現**
   - 相手の話を受けるときの言い回し（「それは大変だったね」「わかるわかる」など）

4. **提案・誘いの言い方**
   - 何かを提案するときのトーン（断定的か、柔らかいか）

5. **文の長さと構成**
   - 短文が多いか、長文で丁寧に書くか

6. **口語的表現・省略語の使用**
   - 「ありがとう→ありがと」「そうなんだ→そうなんだ〜」など

---

# 出力形式

この出力結果は App Group (UserDefaults) の `textStyleProfileData`（JSONエンコード）として保存され、返信文生成時に参照されます。

```json
{
  "tone_profile": {
    "summary": "口調を一言で表現した文",
    "rules": [
      "ルール1",
      "ルール2",
      "...（10項目以内）"
    ],
    "details": {
      "ending_patterns": "語尾のクセの分析結果",
      "emoji_usage": "絵文字・記号の使い方の分析結果",
      "empathy_style": "共感・リアクションの表現の分析結果",
      "suggestion_style": "提案・誘いの言い方の分析結果",
      "message_length": "文の長さと構成の分析結果",
      "colloquial_style": "口語的表現・省略語の分析結果"
    }
  }
}
```
