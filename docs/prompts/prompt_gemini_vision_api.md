この画像はメッセージアプリのトーク画面のスクリーンショットです。画像からチャットの文脈を構造的に読み取り、JSON形式で出力してください。

前置きや説明文は一切不要です。JSONのみを返してください。

---

# 話者の見分け方（アプリ共通のUI原則）

ほぼすべてのメッセージアプリは以下のレイアウト原則に従っています。

- 画面の右側に寄っているふきだし／メッセージ ＝ `me`（自分）
- 画面の左側に寄っているふきだし／メッセージ ＝ `partner`（相手）
- プロフィール画像・アイコンが左側にある発言 ＝ `partner`
- 名前のラベルが表示されている場合はそれも参考にする

---

# 抽出ルール

- テキストメッセージのみ抽出する
- スタンプ・絵文字のみのメッセージ・画像・動画・音声は `"stamp_or_media"` として記録する
- アプリのUI要素（ヘッダー・フッター・ナビゲーションバー・入力欄等）は無視する
- 会話が検出できない / 画面がメッセージアプリでない場合は `"chat_detected": false` を返す

---

# 日付・時刻の抽出ルール

- 画面に「昨日」「今日」「12月3日」のような日付セクションラベルがある場合、そのラベル以降のメッセージすべてに `"date_label"` として付与する
- 個別メッセージに時刻（「17:45」等）が表示されている場合は `"time"` に記録する
- `date_label`・`time` ともに、画面に表示されている文字列をそのまま入れる（変換・推測しない）
- 画面に表示されていない場合は `null` を返す

---

# アプリ識別

画面から読み取れる場合のみ、アプリ名を記録する。

例: `"LINE"`, `"iMessage"`, `"WhatsApp"`, `"Instagram"`, `"unknown"`

---

# 出力フォーマット

必ず以下のJSON形式のみで返してください。

```json
{
  "chat_detected": true,
  "app": "LINE",
  "messages": [
    {
      "speaker": "partner",
      "text": "今日どうする？",
      "date_label": "昨日",
      "time": "17:45"
    },
    {
      "speaker": "me",
      "text": "まだ決めてない",
      "date_label": "昨日",
      "time": "17:46"
    },
    {
      "speaker": "partner",
      "text": "じゃあ6時に渋谷でいい？",
      "date_label": "今日",
      "time": null
    },
    {
      "speaker": "partner",
      "text": "stamp_or_media",
      "date_label": "今日",
      "time": "18:01"
    }
  ],
  "last_speaker": "partner",
  "last_message": "じゃあ6時に渋谷でいい？"
}
```

※ `last_message` はスタンプ・メディアを除いた、最後のテキストメッセージを返す
